# Changelog

**v3.2.1**

- Fixed CEE toggle button positioning in Skillet — now sits inside the button row alongside Ignored List, Queues, and Notes

**v3.2.0**

- Added Skillet-Classic integration — Easy Enchant panel attaches to SkilletFrame when Skillet is managing the craft window
- CEE toggle button appears in the Skillet title bar
- `/cee` now opens the Enchanting window directly (Skillet intercepts if installed)
- Help text moved to `/cee help`

**v3.1.1**

- Polished disenchant list UI with quality-colored icon borders and alternating row shading

**v3.1.0**

- Disenchant window now shows expected disenchant results (dust, essence, shard, crystal) with drop chances on item hover

**v3.0.0**

- Added bulk disenchant module — standalone window for disenchanting bag items (`/cee de`)
- Scans bags for disenchantable gear sorted by bind type (BoP first, then BoE)
- Quality filter checkboxes (Uncommon, Rare, Epic)
- Click to dismiss, Shift+Click to permanently ignore items
- Single secure disenchant button with equip slot whitelist filtering

**v2.0.1**

- Switched release packaging to BigWigs packager for CurseForge flavor support
- Added TBC flavor TOC for CurseForge compatibility

**v2.0.0**

- Initial release
- Spam enchants easily for leveling enchanting
- Side panel attached to the Enchanting UI — drag an item, spam the button
- Secure macro button for spam-clicking without taint
- Auto-confirms "Replace Enchant" popup
- `/cee macro` creates a keybindable macro
